## Como executar
1. Defina a variável de ambiente `MONGODB_URI` com a URI do MongoDB.
2. Rode `ThindeskApplication` (ou `mvnw spring-boot:run`).
3. Acesse http://localhost:8080/login (usuário `admin`, senha `thindesk`).
